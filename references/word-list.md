# 中文首选表达与术语约定

这不是封闭的批准词典，也不是 ASD-STE100 英文词典的翻译。
表外词可以使用。项目正式术语、界面标签和引用原文优先。
以下建议只用于保持原意的改写，不做自动替换。

## 首选表达

检查器读取下面的三列表格，对“待检查表达”做字面匹配并提示复核。
它不分词，也不能判断上下文。命中不等于错误。
第二列中多个表达用顿号 `、` 分隔。
自定义词表也使用这三个列名，至少包含一条有效记录。

| 首选表达 | 待检查表达 | 说明 |
|---|---|---|
| 安装 | 进行安装、执行安装操作 | 不改变安装对象和前置条件 |
| 检查 | 进行检查、开展检查工作 | 保留检查范围和验收条件 |
| 修改 | 进行修改 | 保留修改对象和权限要求 |
| 配置 | 进行配置 | 不改动参数名或参数值 |
| 更换 | 予以更换 | 保留更换条件和时机 |
| 删除 | 予以删除 | 删除与停用不同，不能混用 |
| 使用 | 加以使用 | 专业词中的“利用率”等不需要替换 |
| 启动 | 进行启动操作 | 启动与启用不是同一个概念 |
| 停止 | 进行停止操作 | 停止与关闭电源不是同一个概念 |
| 重启 | 进行重启操作 | 只在原文确实要求重启时使用 |
| 保存 | 进行保存操作 | 保存与备份不同，不能混用 |
| 备份 | 进行备份操作 | 保留备份范围、位置和恢复要求 |
| 连接 | 建立起连接 | 不删除连接协议或目标信息 |
| 断开 | 执行断开操作 | 区分断开连接和断开电源 |
| 确认 | 加以确认 | 不把确认动作改成未经验证的结论 |
| 完成后 | 在完成之后 | 保留动作顺序 |
| 因为 | 由于这个原因 | 只用于原文明确的因果关系 |

## 常用技术词

以下词可作为术语表的起点，不参与脚本匹配：

- 动作：打开、关闭、读取、写入、复制、粘贴、发送、接收、上传、下载、测量、记录。
- 对象：文件、目录、配置、日志、进程、线程、服务、客户端、服务器、数据库、接口。
- 硬件：组件、阀门、螺栓、盖板、端子、电源、指示灯、传感器、控制器。
- 状态：运行、停止、成功、失败、连接、断开、锁定、解锁、只读、可写。

这些词并非彼此等价。“配置”可以是动作，也可以是对象，依上下文使用。
不要照搬英文词典的词性限制。

## 不能机械合并的术语

- 认证：验证身份。授权：授予权限。
- 备份：生成可恢复的副本。保存：写入当前内容。
- 安装：将程序部署到环境。启动：让程序开始运行。
- 启用：允许功能生效。打开：可能指打开文件、界面或物理部件。
- 故障：功能异常。错误：可能指输入、处理结果或错误消息。

具体定义以项目为准。首次使用有歧义的词时给出定义。
繁体原文和地区用语的处理必须结合语境，不能逐字替换技术名称。
